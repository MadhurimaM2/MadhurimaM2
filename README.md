### 🔄 Streaming Service Customer Churn Prediction

**Supervised Learning**

<img src="https://img.shields.io/badge/94%25%20Churn%20Recall-9BBDEB?style=flat" alt="94% churn recall"/>

</div>

- Analyzed 10,000 customer records containing 37 behavioral features to identify customers likely to churn in the next 30 days.
- Engineered 12 additional features capturing customer tenure, engagement, inactivity, and account health, expanding the dataset to 49 features.
- Compared **Logistic Regression, Random Forest, and XGBoost** using ROC-AUC, precision, recall, and F1-score; applied **SMOTE** within training folds to address class imbalance.

### 🛡️ Fake Profile Detection by Clustering

**Semi-Supervised Learning**

<img src="https://img.shields.io/badge/96%25%20ROC--AUC-E9B7D2?style=flat" alt="96% ROC-AUC"/>

</div>

- Developed a semi-supervised learning approach to identify potentially fake social media profiles using unlabelled behavioral data.
- Performed exploratory data analysis and **feature engineering** to prepare profile characteristics for clustering and classification.
- Used **K-Means Clustering**, subject-matter-expert (SME) labelling, and pseudo-label generation to construct training labels for supervised models.
- Evaluated **Logistic Regression, Random Forest, XGBoost** models using hyperparameter tuning and cross-validation on pseudo-labelled data.
- Logistic Regression performed best on the entire dataset with **96% ROC-AUC, 90% precision and 93% recall.**
- The pseudo labels tested against the true labels gave an accuracy of around 90%, thus validating the semi-supervised learning approach.
